# SRS Formalization Engineering Knowledge Vault (v0.1)

Welcome to the Obsidian Engineering Knowledge Vault for the **SRS Formalization Agent**.

## Key Navigation
- **[[Pattern-Index]]**: Human-readable overview of all 21 engineering pattern families.
- **`Index/Pattern-Registry.json`**: Machine-readable JSON mapping for the Python Orchestrator.

## Structure
- **Patterns/**: 21 pattern notes defining structural cues, temporal characteristics, and formalization relevance.
- **Formalization/**: 6 formalization notes providing timed LTL, set theory, and API grammar rules.
- **Concepts/**: 7 domain concept notes covering NASA X-38 software architecture (FCP, FCR, VMEbus, ICP, Watchdog, etc.).
- **Requirements/**: Individual requirement notes (R1 to R22 / SRS194 to SRS195) mapping identified patterns, dependencies, and inconsistencies.
